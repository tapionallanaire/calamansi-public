# Calamansi

Calamansi is an Android emulator frontend for handhelds such as the AYN Thor, Retroid Pocket and AYN Odin 2. It is a fork of [Azahar](https://github.com/azahar-emu/azahar) (3DS) and embeds DS, GB/GBA/NES/SNES, GameCube/Wii, Wii U and Switch engines under one HOME screen.

Downloads are on the [Releases](https://github.com/tapionallanaire/calamansi-public/releases) page. Each release lists its APKs and a `SHA256SUMS` file; check downloads with `sha256sum --check SHA256SUMS`.

Calamansi does not include keys, firmware, BIOS files or games. You must supply your own, dumped from hardware you own.
