# Calamansi

Calamansi is an emulator frontend for Android handhelds such as the AYN Thor, Retroid Pocket and AYN Odin 2, and for Windows PCs. It is a fork of [Azahar](https://github.com/azahar-emu/azahar) (3DS) and embeds DS, GB/GBA/NES/SNES, GameCube/Wii, Wii U and Switch engines under one HOME screen.

Downloads are on the [Releases](https://github.com/tapionallanaire/calamansi-public/releases) page. Each release lists its APKs, the Windows zip (from v0.10.0: unzip it into a folder you can write to and start `calamansi.exe`; the other consoles' engines come inside it) and a `SHA256SUMS` file; check downloads with `sha256sum --check SHA256SUMS`.

Calamansi does not include keys, firmware, BIOS files or games. You must supply your own, dumped from hardware you own.
